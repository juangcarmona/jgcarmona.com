## CONVEX thumbnail

**Symptom.** The recording thumbnail was blank in some dark-theme screenshots and visible in light-theme ones.

**Root cause.** The screenshot script, not the site. The image is correctly `loading="lazy"`, far below the first viewport. The script switched images to eager loading after navigation and waited a fixed 800 ms before a full-page capture. Each run captured dark first, with a cold cache, and the image was not decoded in time. A probe on 2026-11-02 confirmed it: without scrolling, on mobile, the image reported `complete: false` and `naturalWidth: 0` in both themes; after scrolling it into view and waiting for decode, it loaded in all four scenarios. There were no network or console errors, and no theme CSS touches the image (opacity 1, visible, display block).

**Fix.** Captures now scroll the page, wait until every image is complete with a natural width, and only then capture. The site keeps lazy loading. Element captures of the recording exist for desktop dark, desktop light, mobile dark and mobile light.
